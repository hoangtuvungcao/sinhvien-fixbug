## ✨ 2. Tính Năng Nổi Bật

### 🎮 Cơ Chế Chiến Đấu & Điều Khiển
- **Hệ thống bắn Dual-Mode**: Hỗ trợ cả ngắm bắn chuột tự do lẫn tính năng tự động khóa mục tiêu gần nhất.
- **Cơ chế Quá Nhiệt (Overdrive) & Giải Nhiệt Hoàn Hảo (R)**: Nhịp nhàng kiểm soát nhiệt lượng súng, kích hoạt giải nhiệt kịp thời để nhận buff tăng tốc và sát thương.
- **Bộ 3 Kỹ Năng Tác Chiến**:
  - `Space`: Lướt né đòn siêu tốc xuyên qua quái và bẫy độc.
  - `Q` / `Chuột Phải`: Sóng Xung Phản Đạn 360° phản hồi sát thương về phía kẻ địch.
  - `E`: Bão Hoa Dã Quỳ – Chiêu cuối phát trích dẫn tri ân thầy cô, dọn sạch quái trên toàn bản đồ.
- **Hệ thống Xếp Hạng Phong Cách (Style Rank)**: Đánh giá phong cách từ `D` đến `SS` dựa trên chuỗi combo, phản đạn và lướt né sát nút.

### 🌸 Bí Kíp Thầy Cô Truyền Thụ (Skill Tree)
Mỗi lần tích lũy đủ XP từ các mảnh linh kiện bug, người chơi được lựa chọn nâng cấp:
1. **For Loop (Vòng Lặp Vô Tận)**: Tăng tốc độ bắn và lượng đạn xả mỗi giây.
2. **Try-Catch (Bắt Lỗi Ngoại Lệ)**: Tăng giáp hộ thể và khả năng hồi phục khi gặp sự cố.
3. **Cà Phê Ban Mê (Ban Me Coffee)**: Tăng tốc chạy và khả năng cơ động đặc trưng sinh viên phố núi.
4. **Binary Search (Tìm Kiếm Nhị Phân)**: Tăng tỷ lệ và sát thương chí mạng (Crit Chance & Damage).
5. **Mentor Advice (Lời Khuyên Giảng Viên)**: Tăng sát thương diện rộng và hồi chiêu kỹ năng.
6. **Hào Quang Dã Quỳ (Sunflower Aura)**: Vòng hoa xoay quanh tự động thiêu đốt quái áp sát.

### 🎨 Đồ Họa Cyberpunk Anime 3D Cao Cấp
- Xây dựng trên nền **Three.js** với hệ màu Cyberpunk Neon huyền bí kết hợp sắc vàng rực rỡ của hoa Dã Quỳ.
- Sàn đấu Cyber-Lab 140×140m độ tương phản cao, khử hoàn toàn hiện tượng lóa trắng / sương mù mờ ảo.
- Kỹ thuật **MeshToonMaterial** Cel-shading viền nét anime cho hơn 40 mô hình nhân vật, robot và quái vật.
- Hậu kỳ **UnrealBloomPass** chọn lọc giúp đường đạn, tia laser, tia lửa và cánh hoa phát sáng rực rỡ mà không gây chói mắt.
- Tự động nhận diện GPU/máy yếu để tối ưu FPS mượt mà cả trên PC lẫn Mobile.

### 💌 Studio Xuất Thiệp Tri Ân 20/11 (.PNG)
- Sau khi chiến thắng hoặc kết thúc trận đấu, game cho phép người chơi nhập tên, lớp và lời nhắn gửi riêng đến Thầy/Cô.
- Tự động render thiệp 20/11 độ phân giải cao bằng Canvas 2D kèm huy hiệu hoa Dã Quỳ và thành tích trận đấu để tải về máy chia sẻ.

### 🎵 Âm Thanh Độc Quyền (Web Audio Synthesizer)
- 100% âm thanh BGM hành động, SFX tiếng súng laser, lướt né, cảnh báo và nổ được tổng hợp thời gian thực bằng **Web Audio API**.

## 🚀 4. Hướng Dẫn Cài Đặt & Chạy Thử

### Yêu Cầu Môi Trường
- **Node.js** >= 18.0.0
- **npm** >= 9.0.0 (hoặc pnpm / yarn)

### Cài Đặt

```bash
# 1. Kéo mã nguồn về máy
git clone https://github.com/hoangtuvungcao/sinhvien-fixbug.git
cd sinhvien-fixbug

# 2. Cài đặt các thư viện phụ thuộc
npm install --legacy-peer-deps

# 3. Khởi chạy máy chủ phát triển (Development)
npm run dev
```

Truy cập trình duyệt tại địa chỉ: `http://localhost:3000`

### Đóng Gói Sản Phẩm (Production Build)

```bash
# Kiểm tra TypeScript và build tĩnh vào thư mục /dist
npm run build

# Xem thử bản build trước khi deploy
npm run preview
```

Dự án là kiến trúc 100% Client-Side Static, sẵn sàng deploy trực tiếp lên **Vercel**, **Netlify**, hoặc **GitHub Pages** chỉ với 1 click.
